# 分层多智能体协作看板

运行 `node hierarchy-demo/server.mjs` 或 `npm run hierarchy`，打开 http://127.0.0.1:4323/ 。需要本地后台持续运行。已有 .env 不要覆盖，API密钥只在本机配置。

**完整使用说明、模块技术与汇报稿：[Demo完整说明.md](Demo完整说明.md)**。此文件是当前版本说明；早期汇报讲解保留作为历史材料。

当前支持固定摇摆户/营销/风控三团队、五种拓扑、按问题动态链式顺序、自动结束多轮辩论、负责人质疑、Inspector审查、最多两次内容修订、失败隔离、真实API输入输出与用量记录。

动态链式默认结合问题选择顺序，可使用LLM或规则，并在高级设置手动指定六种排列。后续团队读取全部前序已审查消息，最终综合仍有Inspector。执行中跨团队退回和重新规划尚未实现。

辩论默认自动判断何时停止，每轮互读上轮审查快照、回应更新并复审，再评估进展。稳定、无进展、需外部信息或达到上限时明确记录原因，不强求共识。固定轮数在高级设置中保留，自动模式最多3轮。

全部执行真实调用DeepSeek，会产生费用，不自动重试网络请求，不回退假答案。总预算48条请求记录，同时最多两次请求；普通输出最多3000、最终5000 token，单请求总体超时180秒。额外规划、评估、格式纠正和修订均计入预算。TLS验证开启，支持系统网络/VPN TUN及HTTP(S)代理（代理需Node24.14+）。

角色目前共用同一基础模型，尚未接入另一个平台已有Agent的接口、知识库和工具；不是完整论文复现，没有训练业务MasRouter，没有跨任务自进化或业务效果优于单模型的证明。

`node --test` 执行离线回归，不产生API费用。本轮75项测试通过。真实回放记录保存在Git忽略的data目录。详情见完整说明。
